# Treasure Checklist

This draft checklist covers all 20 native treasures represented by the port.
Treasure scoring follows the native shape: finding/locating a treasure gives
initial credit, and leaving it safely in the building gives the remaining
deposit credit.

| Check | Treasure | Native object | Notes |

| [ ] | Several diamonds | `DIAMONDS` | West-bank fissure treasure. |
| [ ] | Bars of silver | `SILVER` | Floor Hole / Y2-side treasure. |
| [ ] | Precious jewelry | `JEWELRY` | Hall of Mountain King side chamber. |
| [ ] | Rare coins | `COINS` | Can be spent for batteries; spent coins cannot later receive building-deposit credit. |
| [ ] | Pirate's treasure chest | `CHEST` | Found through deterministic pirate/chest slice. |
| [ ] | Golden eggs | `EGGS` | Tied to FEE/FIE/FOE/FOO and troll payment recovery. |

| [ ] | Ming vase | `VASE` | Needs the pillow for safe deposit behavior. |

| [ ] | Platinum pyramid | `PYRAMID` | Plover-region treasure. |
